# ADR-005 · XREO first, many companies from day one

**Date:** 2026-11-20 · **Status:** accepted

**Decision.** XREO is the first organisation. Organisations, memberships with roles (owner, admin, approver,
detailer, site, viewer) and row-level security exist from the first migration, so outside firms can join without a
rebuild. Billing (Stripe) comes in Phase 5.
